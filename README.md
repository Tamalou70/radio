# Radio Base Clean — nos titres

Une radio en ligne qui ne passe **que nos propres titres**, faits pour Base Clean.

**Écouter en direct :** https://tamalou70.github.io/radio/

- Chaque station tourne en continu depuis minuit : tout le monde entend le même titre au même moment, comme une vraie radio.
- **Vinyle Rap** : Zéro Retour, album *Poches vides, cœur plein* ; Cash Cash, album *Au dos des tickets* (titre de travail).
- **Animateurs** : Deejay Di et Samantha, à l'antenne sur le direct de Vinyle Rap ; grille d'antenne du jour : [#admin](https://tamalou70.github.io/radio/#admin).
- **Radio Russe** : ALLSIDE.
- **Les paroles** de chaque titre : [paroles/](paroles/README.md), un fichier par titre.
- **L'histoire de Zéro Retour**, en 12 chapitres tirés de ses titres : [artistes/zero-retour-histoire.md](artistes/zero-retour-histoire.md).
- 👍 / 👎 sur chaque titre, gardés dans le navigateur de chacun ; rien n'est envoyé à un serveur.
